# 골드제이 블로그 서포터 (로컬 MVP)

## 실행 방법
1. 이 폴더(`blog-supporter`)를 통째로 내 컴퓨터에 둡니다.
2. `index.html`을 더블클릭하면 크롬·엣지·웨일·사파리에서 열립니다. 설치·서버·인터넷 연결이 필요 없습니다.

## 화면
- **홈**: 다음 발행 글 D-day, 다가오는 발행(2주 안), 진행 보드, 검수 완료 원고 요약
- **발행 캘린더**: 발행일은 직접 정함. 날짜 칸을 누르면 그날을 발행일로 글 추가
- **주제 뱅크**: 새 주제 입력 시 기존 발행 글·계획 글과 키워드 겹침 자동 확인. 발행일은 "발행일 정하기"에서 직접 지정
- **초안 작성**: 브리프 → 골드제이 형식 골격 생성 / Claude 프롬프트 복사. 프로그램명 직접 입력, 인용글은 블로그 글 목록(최신순)에서 선택. 목록에 없는 글은 "블로그 글 목록 붙여넣어 추가"로 넣기
- **초안 검수**: 금지 표현·'피부과'·분량·도입·소제목·사진 구간·줄 길이·제목 자동 검사 + 모바일 미리보기 + 게시 전 수동 체크리스트
- **검수 완료 원고**: 초안 검수에서 "검수 완료 · 저장"을 누르면 그 시점의 원고가 초안 검수 화면 아래 보관함에 버전별로 쌓이고, 같은 원고가 .md 파일로 다운로드 폴더에 저장됨
- 스타일 가이드는 메뉴에서 숨김. 규칙은 검수·골격·프롬프트에 그대로 적용되고, 주소 끝에 `#/guide`를 붙이면 열림

## 글 유형 · 말투
- 글 유형(구성): 원인 감별형(기본) · 오해 바로잡기형 · 원리 해설형 · 비교·선택형 · 총정리형 · 시기·시즌형 · 진료실 칼럼. 유형마다 소제목 구성과 섹션별 목표 분량이 다름
- 말투: 차분한 진료 설명(2026 기본) · 친근한 말투(기존 :) ^^)
- 분량 목표: 공백 제외 2,500~3,000자. 골격은 뼈대(약 700자)만 만들고 ✍️ 자리를 채워야 분량이 나옴. 완성 원고는 "Claude로 초안 쓰기"(Anthropic API 키 필요, 이 브라우저에만 저장) 또는 "Claude 프롬프트 복사"

## 데이터
